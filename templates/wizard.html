Setup Wizard

Let's set up UpdateIP

This takes about five minutes. We will:

  1. choose your time zone and the local name of this app,
  2. connect your Cloudflare account,
  3. search your home network for your UniFi gateway and Nginx Proxy Manager,
  4. connect the devices you choose, testing each one before anything is saved.

The search only looks at private addresses on your own network, and only when you press the button. Nothing is changed on your devices. You can run this wizard again later from the menu.

Connect Cloudflare

Lets UpdateIP change your DNS records when your IP changes. Required

{% if cf_count %}
A Cloudflare account is already connected. You can add another one or continue.
{% endif %}

Create a token that may edit your DNS records. It takes about a minute:

  1. Sign in at dash.cloudflare.com/profile/api-tokens (your own profile, not an account page) and click Create Token.
  2. Next to Create Custom Token click Get started. Give it a name, for example UpdateIP.
  3. Under Permissions add two rows:
    • Zone → DNS → Edit
    • click Add more: Zone → Zone → Read
  4. Under Zone Resources choose Include → All zones (or one specific zone, if you only want that one).
  5. Leave the other fields as they are. Click Continue to summary, then Create Token.
  6. Copy the token now. Cloudflare shows it only once. Paste it below and press Test.

It must be a token from your profile (My Profile → API Tokens). Tokens created under an account's own API tokens page are not accepted.

Find your devices

Finds your UniFi and Nginx Proxy Manager on the network. Optional

These are the networks (subnets) this app can see. Remove the ones you do not want to search, or add others, for example a separate server network.

Devices that do not answer on any common port may not show up. If yours is missing, you can type its address in the next step.
